Before you merge, catch it red-handed.

RedHanded runs each changed npm package in a disposable gVisor sandbox on Vultr, baited with fake credentials and wired to a fake internet with no route out. If the code reaches for the bait, the merge is blocked and the evidence comes with it. Fixed rules decide the verdict; the model only explains it.
